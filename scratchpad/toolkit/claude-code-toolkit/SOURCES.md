# Fuentes

El sistema se apoya en marcos establecidos de documentación de software y en las guías de Claude Code.

## Marcos de arquitectura / documentación
- **C4 model** (niveles Contexto/Contenedor/Componente/Código) — https://c4model.com
- **arc42** (plantilla de 12 secciones para docs de arquitectura) — https://arc42.org/overview
- **ADR** (Architecture Decision Records) — https://adr.github.io/ · MADR — https://adr.github.io/madr/
  · Nygard, "Documenting Architecture Decisions" — https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions
- **Diátaxis** (tutoriales / how-to / referencia / explicación) — https://diataxis.fr/ · Referencia — https://diataxis.fr/reference/
- **Docs-as-code / living documentation**
  - Google eng doc best practices — https://google.github.io/styleguide/docguide/best_practices.html
  - Martin Fowler, "Code As Documentation" — https://martinfowler.com/bliki/CodeAsDocumentation.html
