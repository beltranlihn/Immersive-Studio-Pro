Immersive Studio Pro

Immersive Studio Pro edits video for surfaces that surround an audience: fulldome domes, flat screens, and rooms whose walls and floor are all projection surfaces.

The program runs on the desktop, on Windows and macOS. All rendering happens on the GPU: clips are warped onto the dome in real time, effects run as shaders, and every visible clip is composited into one master image each frame. The viewer displays that master, the live outputs broadcast it, and the exporter records it.

Formats

A sequence works in one of three modes, chosen when it is created.

Dome
A circular fisheye image covering a hemisphere. Clips are placed by direction — azimuth and elevation — and warped onto the dome surface. The master is square and the projected image is the circle inscribed in it.
2D
A rectangular canvas. Clips are placed by horizontal position, vertical position and scale.
360 Room
A set of walls with an optional floor. The walls are unrolled into one wide strip that is edited as a rectangular canvas, and a 3D view shows the result from inside the room.

Formats mix inside one project: a dome project can contain 2D sequences, and a 2D sequence can be placed inside a dome sequence as a clip.

Conventions in this manual

Interface labels appear as they read on screen: Fulldome src. Keys appear as Ctrl+E; on macOS, Ctrl means ⌘. Orange numbers on a screenshot correspond to the numbered list below it.

The interface is in English, with a Spanish translation available in the preferences.

Installing and starting

Requirements

WindowsWindows 10 or 11, 64-bit. On hybrid-graphics laptops the program requests the discrete GPU automatically.
macOSApple Silicon.
Memory16 GB for dome work at 4096 × 4096. Decoding several layers of high-bitrate footage at once is the demanding part.
DiskLocal storage for media. A 4096 × 4096 export at 200 Mb/s occupies about 300 MB per minute.

Installation

On Windows, run Immersive Studio Pro Setup 1.0.0.exe. It installs for the current user, so it requires no administrator rights, and it registers the .isp extension so that double-clicking a project opens it.

The start screen

The program opens on the start screen, where a project is created. The format is chosen first, then its parameters, and a preview shows the result before the project exists.

  1. Choose Dome, 2D or 360 Room.
  2. Set the parameters: resolution, frame rate, dome coverage, or wall geometry for a room. The preview follows each change.
  3. Create the project. The editor opens with an empty timeline.

The start screen is reachable at any time from File → New project… (Ctrl+N). An open project remains open behind it, and Back to project returns to it unchanged.

Demo projects

Demos in the top bar builds a complete project in the chosen format — several tracks, clips, a composition, motion, an effect and automation — and runs a guided tour over it. Everything in it is editable and can be saved as a new project.

Settings

Application settings, including the interface language, are in Project → Preferences…. Settings that belong to the sequence — resolution, frame rate, dome coverage — are in Project → Sequence settings….

How the program is organised

Five ideas describe most of the program's behaviour.

The composite master

Every visible clip is drawn into a single master image each frame. The viewer shows that master, NDI and Spout broadcast it, and the exporter records it. The image on screen while editing is the image that is delivered.

In a dome sequence the master is square and the picture is the circle inscribed in it. The four corners fall outside the projected area: they are recorded as black, or as transparency when the export carries alpha.

Dome coverage

A fulldome master is an azimuthal-equidistant fisheye. Its coverage is the field of view it represents: 180° for a hemisphere, or 200°, 210° and 220° for domes that continue below the horizon. The setting is in Project → Sequence settings… and applies everywhere at once — the warp, the guides, the 3D view and the export.

Coverage describes the venue. A master made at 180° and projected in a 210° dome is wrong at the edges, and repositioning clips does not correct it. The value comes from the dome's specification.

Fulldome source and placed clips

A clip in a dome sequence is treated in one of two ways, set by Fulldome src in the inspector.

Switched off — a placed clip
The footage is a rectangular picture. It occupies a direction and a size on the dome, and the GPU bends it to sit on the curved surface. This applies to material that was not shot for a dome.
Switched on — a fulldome source
The footage is already a dome master: a circular fisheye filling the frame. It is drawn into the master one to one, since it already covers the whole sky. Generated compositions are fulldome sources.

Equirect 360° handles equirectangular 360° footage and reprojects it into the dome. Fisheye, with its Amount, bends a fulldome source further; it becomes available once Fulldome src is on.

Sequences are media

A sequence is an item in the media panel, and an item in the media panel can be placed on a track. One mechanism therefore provides sequence tabs, nesting and generated compositions. Chapter 15 describes it.

Clips

Video, stills, audio, text, shapes, generated compositions, nested sequences and adjustment layers are all clips on tracks. They trim alike, carry the same inspector sections where those apply, and animate alike.

A first project

This walkthrough creates a dome sequence, imports footage, places it, animates it, adds a generated composition and exports a master.

Create the sequence

  1. On the start screen choose Dome.
  2. Set the resolution to 4096 × 4096 and the frame rate to the value the venue uses.
  3. Set coverage to the dome's field of view.
  4. Create the project.

Import footage

Drag files onto the media panel, or press Ctrl+I. Video, stills, audio and image sequences are accepted. For heavy footage, right-click the item and choose Generate proxy; chapter 10 covers proxies.

Place a clip on the dome

  1. Drag a clip from the media panel onto a video track.
  2. Select it and open Transform in the inspector.
  3. Drag Azimuth to swing it around the horizon, Elevation to raise it towards the zenith, and Size to enlarge it.

Dragging the clip in the viewer moves the same two values.

Elevation accepts negative values, which place a clip below the horizon. In a dome with coverage above 180° that is projected area.

Add movement

Open Motion in the inspector and click a preset: Orbit travels around the horizon, Float drifts slowly. A preset adds ordinary modifiers to the list, which can then be retuned, switched off or deleted one at a time.

For a movement with an exact start and end, use keyframes: place the playhead, set the value, and a keyframe is recorded. Chapter 19 covers both routes.

Fill the dome with a composition

  1. Select two or three items in the media panel.
  2. Click Compose in the create row.
  3. Choose a type — Ring is the simplest — and set the count.
  4. Confirm. The composition arrives on the timeline as one clip.

The composition is a nested sequence containing real clips. Double-clicking it opens its contents for editing, and its generating parameters remain in the inspector.

Export a master

  1. Open File → Export… (Ctrl+Shift+E).
  2. Choose the destination folder with Choose….
  3. Select MP4 H.264 · GPU, up to 4096.
  4. Set Quality to Maximum and check the bitrate.
  5. Press Export.

Projects are saved with Ctrl+S as .isp files.

  1. Menu bar — File, Edit, Project and Window. Chapter 25 lists every entry. At the right of the same bar, the format chip shows the active sequence's format, resolution, frame rate and export codec, and opens the sequence settings.
  2. Media panel — everything the project contains. Chapter 6.
  3. Viewer — the master image, in 2D or 3D. Chapter 7.
  4. Inspector — the selected clip's parameters. Chapter 9.
  5. Transport — playback controls, timecode, sequence tabs and the editing well. Chapter 8.
  6. Timeline — tracks, clips, ruler, markers and automation lanes, with the tool rail down its left edge. Chapter 8.

The status bar along the foot of the window describes what the active tool does, and shows CPU, memory and GPU load with the project's media and clip counts.

Panels

Dragging the gutters between panels resizes them. The media and inspector panels collapse from Window, or from the two buttons at the top right of the inspector. The timeline's height is dragged from its top edge.

The command palette

Ctrl+K, F1 or ? opens a searchable list of every command with its shortcut.

Preferences

Output to a projector

Two arrangements send the picture to a display without the interface around it, both under Window and in the Output menu above the viewer.

  • Full performance — the viewer occupies the whole window.
  • Viewer-only window — a second window for another display, showing the complementary view: 3D while the editor shows 2D, and the reverse.

The media panel

The media panel holds everything the project contains, including the sequences and compositions the program generates.

  1. Kind filters — all items, video, stills, audio.
  2. Sort — by Name, Date or Type.
  3. View — list or grid.
  4. Import — opens the file picker; also Ctrl+I.
  5. Text — creates a text item: font, weight, alignment, fill and outline colour, with custom fonts loadable from file.
  6. Compose — builds a generated composition from the selected items. Chapter 16.
  7. Adjust — creates an adjustment layer, a clip with no picture that applies its effects to everything composited below it.

Below the create row, each item shows its name, kind, resolution and duration.

Between Text and Compose, Shape creates a rectangle, ellipse or line with a fill and a stroke.

Search

Ctrl+F reveals a text filter in the filter row; Esc closes it.

Folders

Right-clicking empty panel space creates a folder. Folders nest and accept colours, and items are dragged between them. Renaming an item, moving it between folders, and creating, renaming or deleting a folder are all undoable.

Selecting

Clicking selects, Shift+click extends a range, and Ctrl+click adds or removes one item. Multiple selection applies to generating several proxies at once and to building a composition from a set of sources.

The viewer

The viewer displays the composite master. It has a 2D mode, which shows the master as it will be delivered, and a 3D mode, which shows it mapped onto the dome or room.

  1. View mode — 2D master or 3D preview.
  2. Overlays — grid, outline, horizon fade, and the floor rectangle in a room.
  3. Preview quality — Full, ½ or ¼. Lowering it eases playback and leaves the export untouched.
  4. Clip and Comp — whether the viewer shows the selected clip alone or the whole composite, and whether composition caching is in use.
  5. Zoom — the percentage, with the wheel over the viewer as an alternative. The hand tool pans.
  6. Output — full performance, the viewer-only window, and the NDI and Spout broadcasts. Chapter 24.

When the window is narrow, the bar folds its less-used controls into a … menu.

2D and 3D

The 2D view serves for framing and delivery. The 3D view shows the shape an audience sees: a clip that reads clearly as a fisheye can be strongly distorted overhead, and the 3D view reveals that. In 3D, Orbit moves the camera freely and Viewer places it where a person stands.

Working in the viewer

Clips are dragged directly in the viewer: in a dome this moves azimuth and elevation, and in a 2D or room sequence it moves horizontal and vertical position. Point masks are drawn on the viewer canvas as well; chapter 17 describes them.

The dome circle is the picture. Material that appears in the corners of the 2D view lies outside the projected image and is recorded as black, or as transparency when the export carries alpha.

The timeline

  1. Ruler — the time scale. Dragging it scrubs the playhead, and markers occupy its lower half.
  2. Clip — the diamonds along its lower edge are keyframes, and the small handles in its upper corners make fades.

Video tracks stack from the bottom up: a clip on V3 draws over a clip on V1. Audio tracks sit at the foot of the column and carry a subtle tint.

Track headers

Right-clicking a header adds, duplicates, renames, colours or deletes a track. Dragging a header up or down reorders the tracks. In a room, floor tracks carry a blue-framed tag.

Tools

  1. Select (V) — selects, moves and trims.
  2. Track select — selects everything from the click onwards.
  3. Hand (H) — pans the view.
  4. Trim (T) — contextual trim: ripple, roll, slip and slide.
  5. Razor (B) — cuts a clip.
  6. Zoom (Z) — zooms to the click.

The transport

  1. Sequence tabs — the open sequences. Chapter 15.
  2. Playback — go to start, play, go to end, and the in and out marks. Space plays and pauses.
  3. Timecode — the playhead position, with the frame count beside it.
  4. Display — timecode or frames.
  5. Loop — sets the loop range from the time selection.
  6. Marker — drops a named marker at the playhead; also M.
  7. Editing well — Auto shows automation curves over the clips, Grid toggles grid snapping, Fit zooms to the whole project.

Shuttle

J and L shuttle backwards and forwards; pressing either again gives 2×, 4× and 8×. K stops. ↑ and ↓ jump to the previous and next cut.

With a loop range set, playback started inside the range loops, and playback started outside it runs straight through.

Markers

The inspector

The inspector holds the selected clip's parameters in collapsible sections. The sections shown depend on the kind of clip: an audio clip has no Transform, an adjustment layer has no Source.

  1. Tabs — Inspector and Reactive FX, the audio-driven effects chain described in chapter 20.
  2. Transform — position on the dome or canvas.
  3. Parameter rows — a name, a coloured track, a value box and a keyframe diamond.
  4. Clip — opacity, blur, crop, mask, blend mode and black key. Chapter 17.
  5. Source — how the footage is interpreted. Chapter 12.
  6. Playback — speed and looping. Chapter 11.
  7. Color — grading and LUTs. Chapter 18.
  8. Motion — procedural movement, with the effects chain below it. Chapter 19.

Parameter rows

  • Dragging the track changes the value.
  • Double-clicking the value box allows an exact number to be typed.
  • Clicking the diamond sets a keyframe at the playhead; clicking a filled diamond removes it.
  • The track's colour identifies the parameter and is reused for its automation curve.

On a parameter that already carries keyframes, changing the value writes a new keyframe at the playhead rather than moving the whole curve. On a parameter without keyframes, the value simply changes.

Header

The top of the inspector shows the clip's thumbnail, name and kind, with a Source button that opens the source monitor on that item.

Whether numbered images form a sequence is decided by the command used, before the file picker opens.

Proxies

A proxy is a light, all-intra copy of a heavy clip, used while editing. Proxies are generated on request: right-click an item and choose Generate proxy, or select several items first to queue a batch.

  • Importing heavy footage prompts a reminder in the status bar that the option exists.
  • Proxies already on disk are adopted automatically, both when a project is reopened and when the same footage is imported again.
  • A proxy whose generation was interrupted is detected and discarded.

With long-GOP camera masters, scrubbing a frame can take over a second. A proxy brings that to a few milliseconds.

The source monitor

Double-clicking a media item, or pressing Source in the inspector, opens the source monitor: a floating player for reviewing material and marking a range.

  • I and O set the in and out points, Space plays, and the arrow keys step one frame.
  • The window stays open while work continues. It moves, resizes from its corner, and closes with Esc.
  • Marks belong to the item, are saved with the project, and apply when dragging from the media panel. An item that will enter trimmed shows its duration in brackets.
  • Marks change only through an explicit gesture, so reviewing material leaves them as they were.

Relinking and replacing

Relink
Points an item at a file that has moved; every clip using it follows.
Replace media
Exchanges the footage under existing clips while keeping their position, duration, effects and automation. A looping clip loops over the full duration of the new footage and keeps its length on the timeline. This applies inside nests and compositions as well.

Text and shapes

Text items carry font, weight, alignment, fill colour and outline colour, and accept custom font files. They render at a high internal resolution so they stay sharp on a 4K dome; the proportion of the canvas governs the result, so there is no pixel-size field.

Saving

Projects are .isp files in JSON, written atomically with a .bak alongside. The program autosaves, keeps a recovery history, and writes incremental versions — _v01, _v02 — from the right-click menu on the Save button.

Editing in the timeline

Moving clips

Dragging a clip anywhere on its body moves it, and a ghost shows the landing position. Alt+drag copies. Linked audio and video move together, and the linked partner is held to horizontal movement so the pair stays on matching tracks.

Overlapping

Dropping a clip on top of another trims the stationary clip, and splits it in two when the new clip lands in the middle. The source file is untouched, and no crossfade is created.

Trimming

Handles
With the select tool, dragging either end of a clip trims it.
Contextual trim, T
The trim tool chooses the operation from the grab point: ripple at an outer edge, roll on a cut, slip in the middle of a clip, slide below it. A linked partner is trimmed to match.

Fades and crossfades

Each clip carries a small handle in its upper corners.

  • Dragging it inwards makes a fade in or out.
  • Dragging it outwards over a cut makes a crossfade with the neighbouring clip. Video crossfades geometrically and audio crossfades by gain.

Cutting and deleting

RazorBClicking cuts.
Split at playheadCtrl+ECuts the selection, or every clip under the playhead.
DeleteDelLeaves a gap.
Ripple deleteShift+DelCloses the gap.

Copy and paste

Copying takes the whole selection. On pasting, each clip lands on its own track at its original spacing relative to the first, so a multi-layer arrangement returns intact. Linked pairs are relinked when both halves were copied.

Copy and paste attributes

Ctrl+Alt+C and Ctrl+Alt+V carry the properties of a clip — transform, looping, speed, colour, masks, effects, motion and all automation — to another clip. This works in both directions between an ordinary clip and a composition.

Identity, position, duration and the media itself stay with the destination, which keeps its place and its length on the timeline. A composition's generating configuration stays with its own composition.

Automation is trimmed to fit. Pasting from a 40-second clip onto a 15-second clip keeps the automation that fits, and inserts the interpolated value at the start when the first surviving keyframe falls later, so the curve begins at the right value.

Selection and snapping

  • Dragging on empty timeline space makes a marquee; dragging on the ruler makes a time selection, which becomes the loop range.
  • Snapping catches clip edges, the playhead, markers and the grid.
  • Ctrl+D duplicates, and Alt+← and → nudge by one frame.

Speed and looping

Speed
50 % to 200 %. Changing it stretches the clip together with its automation, so keyed movement stays in the same place relative to the picture.
Loop
Repeats the source for the length of the clip. The inspector shows the cycle length and the part of the source it repeats, in timecode.
From clip
Reads the cycle length from the clip's current duration.

Switching looping off trims the clip to the remaining length of the file. To redefine a cycle, use From clip, which changes the cycle length alone.

The clip menu

Placing clips in the dome

Transform

AzimuthBearing around the horizon, in degrees. 0° faces the front of the dome.
ElevationHeight above the horizon, in degrees. 90° is the zenith. Negative values place a clip below the horizon, which is projected area in a dome with coverage above 180°.
SizeHow much of the dome the clip subtends.
RotationRoll about the clip's own centre.
MirrorFlips the clip horizontally.

Each value can be dragged, typed, keyframed and animated. Dragging the clip in the viewer moves azimuth and elevation together.

Shape on a curved surface

A rectangle placed on a dome becomes a curved quadrilateral, and the effect grows with size and with height. Two consequences follow.

  • A large clip near the zenith stretches noticeably, which the 3D view shows.
  • Near the zenith one degree of azimuth covers a short distance. For this reason the Float motion preset animates in the dome plane rather than in azimuth and elevation, so the same drift reads the same wherever the clip sits.

Source

Fulldome src
For footage that is a dome master — a circular fisheye filling the frame. It is drawn one to one.
Equirect 360°
For equirectangular 360° footage, reprojected into the dome.
Fisheye and Amount
Bends a fulldome source further. The row becomes available once Fulldome src is on, with a tooltip explaining the dependency. Switching Fulldome src off also switches this off.

A generated composition covers the whole dome, so its clip arrives with Fulldome src already on. Placement happens inside it, on the elements it contains.

Adjustment layers

An adjustment layer is a clip with no picture of its own. It applies its effects chain across the full dome to everything composited below it, and carries the complete effects catalogue.

2D sequences

A 2D sequence uses a rectangular canvas. The rest of the program behaves as it does in a dome.

2D inside dome work

Two parts of the program use flat sequences directly.

  • Compositions are built flat. The Weave composition lives in a 1:1 flat nest, where neighbouring strips meet at right angles, and enters the dome as a fulldome source with fisheye applied to the whole assembly at once.
  • The floor of a 360° room is edited as a flat area of the room canvas.

Project → New sequence… adds a 2D sequence to a project of any format.

The 360° room

A room treats several projection surfaces as one piece: walls unrolled into a single wide strip, an optional floor, a 3D view from the audience position, and an export that delivers the whole strip or one projector's area at a time.

Geometry

The room is defined when the project is created, and reconfigured from Project → Room geometry….

Each wall carries a role — front, right, back, left — a physical width and height in centimetres, and a pixel resolution. The plan preview solves the wall loop into a floor plan and reports geometry that fails to close, or that closes by crossing itself.

Centimetres describe the room; pixels describe the canvas. The strip is measured in pixels, and its width is the sum of the walls' pixel widths. The physical measurements give the 3D view its proportions and derive the floor.

The strip

The strip is edited as a 2D canvas: clips take a horizontal position, a vertical position and a scale, and a clip can span a seam and run across two walls. The seams and labels are guides.

Floor content goes on floor tracks, marked by a blue-framed tag in the track header. The floor is a band of the same canvas, so one composite covers every surface.

The 3D view

The content is drawn unshaded, since the view previews what will be projected. The shading visible on the outside belongs to the translucent shell around the room.

Exporting a room

Full stripThe walls as one wide file.

Sequences and nests

A sequence is a media item, and a media item can be placed on a track. Sequence tabs, nesting and generated compositions all follow from this.

Tabs

Tabs hold a fixed width so the bar stays still as sequences are renamed. Three are visible at a time and the rest are reached with the wheel over the tabs. Dragging a tab reorders it, and + creates a sequence.

Creating a sequence

Nesting

Selecting clips and choosing Nest selection from the Edit menu, or from the clip menu, replaces them with a single clip containing them. Double-clicking it opens its contents, and the tab bar shows the current position.

  • A nested clip holds an independent copy, so editing it leaves the originals as they were.
  • In a dome sequence a nest is created as a fulldome source: it composites internally and enters the dome as a complete dome image.
  • Shortening the contents of a nest shortens its instances in the parent sequence.

Audio inside a nest

Sound plays from audio tracks that are visible. A nest containing audio tracks therefore creates a derived audio clip in the parent, linked to the video clip, which moves, trims and unlinks like any A/V pair.

Composition proxies

A nest can be cached as a single video, so playback decodes one stream instead of many. The cache renews itself when the contents change.

Render in place

Render in place… in the clip menu bakes a clip or a nest to a silent MP4 and replaces the timeline instance with the baked file on a new track. A progress view shows the live frame, a bar and an estimate, and offers cancellation.

Compose

Compose builds an arrangement out of media items — a ring of clips around the horizon, a tunnel approaching the viewer, woven strips filling the dome — and returns it as an editable nested sequence.

Building a composition

  1. Select the items to use in the media panel.
  2. Click Compose in the create row.
  3. Choose a type and set its parameters. The preview follows each change.
  4. Confirm. The composition lands on the nearest track with room for it.
  1. Type — the layout to generate.
  2. Media basket — the items the composition contains, with thumbnails, names and order. × removes one; dragging from the media panel, or double-clicking there, adds one. The order decides which source goes where.
  3. Mask — a shape and a size from 0 % to 100 %, applied to every element. This turns square footage into a ring of circles in one step.

Tunnel

Tunnel sources are 1:1 images with alpha, marked as fulldome, that start small and grow until they leave past the edge of the dome. Any distribution of alpha works; a ring reads as a legible tunnel. Each element is phase-shifted, which makes the stream continuous.

From and To
The size range each element travels through.
Speed
The rate of travel.
Depth
Bends the growth curve. An exponential rise reads as perspective, since approaching a viewer at constant speed multiplies the radius.
Spin
Degrees of rotation per cycle. A perfectly symmetrical source hides it.
Helix
Pushes elements off the axis in a spiral, visible with any source.
Fade in and Fade out
Separate envelopes, each with an amount as a percentage of the cycle.

Elements are drawn in depth order every frame, since their ranking by nearness rotates as they cycle.

Weave

Weave keeps its sources undistorted: the side that crosses a strip takes the strip's thickness, and the other follows the media's proportions. Each strip uses one source. The interlacing is decided per crossing, so the pattern stays still while the strips flow through it.

Layout
Woven, Lines ↔ or Lines ↕.
Strips
1 to 24 per direction, one source each.
Strip width
A percentage of the step. At 100 % strips touch and fill the dome; below that a transparent gap opens. Width and spacing are one control.
Packing
Reaches 100, where one clip begins as the previous ends.
Direction
One way, The other, Alternate or Still.
Order
Shuffles which source goes to which strip.

Editing a composition

Two surfaces edit the same values.

  • The inspector shows the type, the two most-used parameters for that type, and More options….
  • The dialog reopens the full parameter set.

The composition is a nest, so its contents can also be opened and moved by hand. Manual changes survive regeneration.

A composition lands on the nearest track with a free gap for its duration, measured from the selected track header, or from the bottom when no track is selected. A new track appears only when no existing track has room.

Masks

Shape masks

The Mask menu offers Circle, Rounded, Diamond and Vignette, and Custom takes a PNG as a matte. A size control scales the mask and a feather softens its edge.

Point masks

Add mask draws a mask by clicking points directly on the viewer canvas. A clip can carry several, each with its own invert and feather, which isolates part of a shot rather than cutting it to a geometric shape.

The effects chain

Effects appear in the Effects section of the inspector and in the Reactive FX tab, which show the same chain. Add Effect adds one, dragging reorders, the power button switches one off, and the bin removes it.

Every effect parameter accepts keyframes, and every effect accepts audio drive. Chapter 20 covers the audio side and chapter 28 lists all 26 effects with their parameters.

To treat the whole picture rather than one clip, use an adjustment layer, created from Adjust in the media panel or from Add Adjustment Layer in the Reactive FX tab.

Colour

Colour is set per clip and runs in the shader, so it applies identically in the viewer, the live outputs and the export.

A tone curve with Luma, R, G and B channels. Clicking adds a point, dragging shapes the curve, and Reset straightens it.

LUTs

LUT → Load… imports a .cube 3D LUT and applies it per clip as the final step of the colour chain. A look developed in a grading application travels this way.

A dome is a large, close, curved surface. Material judged on a monitor often reads brighter in the venue, so exposure decisions hold better when made on the dome itself, or at least in the 3D view.

Motion, keyframes and automation

Movement comes from two mechanisms. Motion is procedural: endless, parameterised, with no keyframes. Automation is keyframed: exact values at exact times. They stack, and a mix control balances them.

Clicking a preset chip adds a modifier. A preset stamps ordinary modifiers into the list, which are then retuned, switched off or deleted individually.

Waveforms

Loop
Grows without end, for continuous travel.
Wave
Goes and returns.
Saw
Rises to the amplitude and restarts at zero, for a cycle that repeats: an endless scroll, a tunnel. Its Curve control from 0 to 100 bends the rise, and an exponential rise reads as perspective.

Float

Float is a chord rather than a single parameter: horizontal drift, vertical drift and a gentle roll, out of phase with one another. Its three modifiers carry periods of 11, 14 and 18 seconds, which share no common multiple, so the combined path does not repeat. A master Intensity control from 0 % to 300 % scales the chord and preserves values retuned by hand.

In a dome, Float uses the slide parameters rather than azimuth and elevation, since one degree of azimuth covers less ground near the zenith than at the horizon.

Keyframes

Every parameter row carries a diamond, which sets a keyframe at the playhead and removes it when already filled. Once a parameter carries a keyframe, editing its value writes another one at the playhead.

The automation lane

Each track shows one parameter's curve, chosen by two chips in the track header: the left chip picks the category or device — Transform, Clip, Color, or any Motion or Effect in use — and the right chip picks the parameter. A ◆ marks what is already automated. Touching a parameter in the inspector brings its curve into view.

Working on a curve

  • Clicking adds a point, dragging moves it, right-clicking types an exact value.
  • Dragging a selection over several points allows them to be nudged, scaled or tapered.
  • The shape box applies a free transform to a selection.
  • Easing presets apply standard cubic-bezier shapes to a segment.
  • Simplify thins a dense curve and keeps its shape.
  • A curve can be copied and pasted at the click position.

Mixing motion and automation

Each Motion modifier carries a Mix from 0 % to 100 %, and the mix accepts keyframes. A procedural drift can therefore fade in and out across a scene while keyframes handle the composition underneath.

Modulation

A parameter can also be driven by a stack of modulation layers — LFOs, audio followers and spatial functions — from the modulation panel, which suits a value that wanders rather than arrives.

Exporting

  1. Render monitor — the frame the encoder has just written.
  2. Codec — the format and encoder, listed below.
  3. Destination — Choose… sets the folder before the render starts.
  4. Quality — Maximum, Balanced or Fast.
  5. Bitrate — in Mb/s, with a suggested figure for the chosen size.
  6. Frame rate — the output rate.
  7. Estimate — file size, frame count and dimensions.
  8. Export — starts the render.

Quality and bit depth

For a 4096 × 4096 master, 150 to 250 Mb/s at Maximum covers delivery. Bit depth offers 10-bit on H.265, which suits the large smooth gradients that appear across a dome.

Presets

Save beside the Preset menu stores a configuration for reuse — one per venue, for example.

The queue

Jobs run one at a time. A room export in Each wall + floor mode queues one job per surface. Elapsed, remaining and written counters sit beside the render monitor.

A 4096 × 4096 export is a long operation. Running it for a minute, stopping, and opening the file in the player that will be used confirms the settings before the whole piece is committed.

Viewing and recording

Window → Show corner data draws it in the viewer, as a view setting. Corner data → Burn into the unprojected corners in the export sheet records it into the file. The two switches are independent: an exported master carries corner data when the export switch asks for it.

Details

  • The timecode counts exported frames, so it matches the delivered file.
  • Text blocks shrink automatically when a long title would reach the projected circle.
  • In a dome sequence the picture is clipped to the circle before the corner data is drawn.
  • An optional black background fills the corners for players that expect opaque frames.

Performance and problem solving

Smooth playback

  1. Generate proxies for heavy footage. With long-GOP camera masters this gives the largest gain.
  2. Lower the viewer quality to ½ or ¼, which leaves the export untouched.
  3. Cache heavy compositions with a composition proxy, so playback decodes one stream.
  4. Render in place anything finished and expensive.
  5. Mute tracks that are not being judged.

Situations

An element inside a composition looks softer than the same footage placed directly
Compositing passes through an intermediate buffer whose resolution follows the output size. Exporting at the sequence's own resolution keeps the detail.
Part of a clip appears in the corners of the 2D view
That area falls outside the fulldome circle and records as black, or as transparency with alpha. Reducing the clip's size or moving it brings it inside.
An export refuses a resolution
The built-in H.264 reaches 3072 × 3072 and the built-in H.265 about 1080 × 1080. The entries marked GPU reach 4096 and 8192.
A clip plays every second frame
Its proxy was generated at half the source's frame rate. Deleting the proxy and generating it again restores the rate.
A clip shortened when looping was switched off
Switching looping off trims the clip to the remaining length of the file. Ctrl+Z restores it, and From clip redefines a cycle without switching the loop off.
A project opened with an unexpected format or framing
Factory defaults apply before every project is read. Project → Sequence settings… shows the sequence's current values.
The 3D view is black
On a hybrid-graphics laptop, the program requests the discrete GPU automatically; a system-level override can redirect it.

Recovering work

  • Projects save atomically with a .bak alongside.
  • Restore last autosave and Recovery history… are in the command palette.
  • Save incremental writes _v01, _v02 and so on, which suits the moment before a large restructuring.

Reporting a problem

Save diagnostics log… in the command palette writes a log describing the environment and recent activity.
